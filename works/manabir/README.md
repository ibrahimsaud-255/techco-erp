# منابر — منصة تنظيم الأنشطة الدعوية في المساجد

منصة موحّدة تربط **الدعاة والأئمة** بـ **المساجد** و**الجهة الإدارية** و**الوزارة**:
تقديم الطلب ← المراجعة الإدارية ← الرفع للوزارة ← الاعتماد وإصدار الرقم الرسمي ← التنفيذ والتقرير.

> هذا المجلد **مستقل تماماً**: انسخه كما هو إلى أي استضافة أو نطاق وسيعمل مباشرة،
> بدون تنصيب، وبدون أدوات بناء، وبدون أي اعتماد على موقع آخر.

---

## ١) التشغيل السريع

### على الاستضافة (الطريقة المعتمدة)
ارفع محتويات هذا المجلد إلى مجلد الموقع (`public_html` أو ما يماثله) ثم افتح النطاق.
يعمل على أي استضافة تدعم الملفات الثابتة: Hostinger, cPanel, Netlify, Vercel, GitHub Pages, Cloudflare Pages.

### على جهازك للتجربة
افتح `index.html` مباشرة بالمتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## ٣) بنية الملفات

```
manabir/
├── index.html            هيكل الصفحة (ملف واحد فقط)
├── config.js             ← الإعدادات: مصدر البيانات، مقاطع الشرح، مفاتيح الربط
├── schema.sql            مخطط قاعدة البيانات (يُنفَّذ مرة واحدة عند الربط)
├── README.md             هذا الملف
├── دليل-الاستخدام.md      شرح المنصة للمستخدمين حسب الدور
├── media/                مقاطع الشرح (فيديو أفقي + عمودي)
└── assets/
    ├── app.css           نظام التصميم الكامل (Liquid Glass)
    ├── icons.js          الأيقونات (SVG مرسومة داخلياً — لا إيموجي ولا مكتبات)
    ├── ui.js             أدوات الواجهة: النوافذ، الأدراج، التنبيهات، التواريخ
    ├── data.js           البيانات التأسيسية والأدوار والصلاحيات
    ├── store.js          طبقة البيانات: الحفظ، الاستعلامات، دورة حياة الطلب
    ├── views-core.js     المكتب · لوحة المعلومات · التقويم · الشرح · التقديم العام
    ├── views-requests.js الطلبات وتفاصيلها وإجراءاتها وخطاب الاعتماد
    ├── views-directory.js دليل المساجد ودليل الدعاة
    ├── views-admin.js    الاعتمادات · التقارير · المستخدمون · الإعدادات
    └── app.js            التوجيه، القائمة، البحث، الجلسة
```

لا توجد أي حزم npm، ولا خطوة بناء، ولا اتصال بخوادم خارجية عدا خط الكتابة من Google Fonts.

## ٤) أوضاع التشغيل

في `config.js` مفتاح واحد يحدّد مصدر البيانات:

### أ) وضع العرض `dataSource: "local"` — الوضع الحالي
- البيانات محفوظة في متصفح كل مستخدم (localStorage).
- مناسب للعرض على العميل وتجربة كل الأدوار والسيناريوهات فوراً.
- كل مستخدم يرى نسخته، ولا تنتقل البيانات بين الأجهزة.

### ب) وضع الإنتاج `dataSource: "supabase"` — بعد الاعتماد
1. أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com).
2. من **SQL Editor** الصق محتوى `schema.sql` واضغط Run (ينشئ الجداول والصلاحيات).
3. من **Project Settings ← API** انسخ `Project URL` و `anon public key`.
4. ضعهما في `config.js`:

```js
dataSource: "supabase",
supabase: { url: "https://xxxx.supabase.co", anonKey: "eyJhbGciOi..." }
```

عندها تصبح البيانات مشتركة بين كل المستخدمين على كل الأجهزة، مع حماية على مستوى الصف
(كل دور لا يرى إلا ما يخصّه) كما هو معرّف في `schema.sql`.

## ٥) تخصيص الهوية

من داخل المنصة: **الإعدادات ← الهوية** (اسم المنصة، الجهة الإدارية، الجهة المعتمِدة، بيانات التواصل).
وللتغيير في الملفات مباشرة:

| ما تريد تغييره | المكان |
|----------------|--------|
| الألوان | `assets/app.css` — قسم «الرموز» في أعلى الملف (`--teal-700` وأخواتها) |
| الشعار | `assets/favicon.svg` وأيقونة `mosque` في `assets/icons.js` |
| الخط | سطر `@import` في أول `assets/app.css` |
| اسم المنصة والجهات | `assets/data.js` ← `SETTINGS`، أو من شاشة الإعدادات |
| المساجد والدعاة | من داخل المنصة (الأدلة)، أو `assets/data.js` للبيانات الأولية |

## ٦) مقاطع الشرح

شاشة **شرح المنصة** جاهزة لعرض مقطعين: أفقي للكمبيوتر وعمودي للجوال.
ضع الملفات في مجلد `media` بالأسماء التالية:

- `media/guide-desktop.mp4` — أفقي 1920×1080
- `media/guide-mobile.mp4` — عمودي 1080×1920
- `media/guide-poster.jpg` — صورة الغلاف (اختيارية)

قبل رفعها تظهر بطاقة توضيحية مكانها، ولا يتأثر شيء في المنصة.
التفاصيل في `media/اقرأني.md`.

## ٧) بعد أي تعديل على الملفات

المتصفحات تحتفظ بنسخة مخبّأة من الملفات. بعد كل تحديث، ارفع رقم الإصدار في `index.html`:

```html
<link rel="stylesheet" href="assets/app.css?v=1.0.2" />
<script src="assets/app.js?v=1.0.2"></script>
```

(غيّر `1.0.1` إلى `1.0.2` في كل الأسطر) ليأخذ الجميع النسخة الجديدة فوراً.

## ٨) ما تغطّيه المنصة

- **المكتب**: كل الأقسام كتطبيقات في شاشة واحدة، مع عدّادات حيّة.
- **لوحة المعلومات**: مؤشرات ومسار الطلبات ورسوم بيانية — تختلف حسب الدور.
- **الطلبات**: تقديم، فلترة، تفاصيل كاملة، سجلّ زمني لكل إجراء، تصدير CSV.
- **دورة الاعتماد**: مراجعة إدارية ← رفع للوزارة ← اعتماد برقم رسمي ← خطاب قابل للطباعة/PDF.
- **التقويم**: توزيع الأنشطة على المساجد شهرياً، وكشف تعارض المواعيد تلقائياً.
- **دليل المساجد**: البيانات، التجهيزات، التوفّر خلال ٧ أيام، سجل الأنشطة.
- **دليل الدعاة**: التخصصات، التصاريح وتاريخ انتهائها، التقييم، السجل.
- **التقارير**: الحضور، نسبة الاعتماد، التوزيع حسب النوع والفئة والحي.
- **المستخدمون والصلاحيات**: خمسة أدوار بمصفوفة صلاحيات واضحة.
- **روابط التقديم**: رابط خاص يُرسل للداعية ليقدّم طلبه دون حساب.
- **شرح المنصة**: مقاطع تعريفية + بداية سريعة لكل دور + أسئلة متكرّرة.

يعمل كل ذلك على الجوال والكمبيوتر، بالعربية واتجاه RTL كامل، مع مظهر نهاري وليلي.
