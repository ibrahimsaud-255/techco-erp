# نظام إدارة الشركة التقنية (نسخة عمل)

نسخة مطوّرة من النظام الداخلي الأصلي (موقع إبراهيم سعود) — مجهّزة لإدارة أعمال الشركة التقنية الجديدة.
النظام تطبيق **HTML ثابت** يكلّم **Supabase** مباشرة، بدون أي خطوة build.

> ⚠️ الاسم «الشركة التقنية» **مؤقت** — يتغيّر بسطر واحد عند تسجيل اسم الشركة (انظر «تغيير الهوية» أدناه).

---

## التشغيل محلياً

من داخل مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح: <http://localhost:8000/>  (يحوّلك تلقائياً إلى `/app/` = النظام).

أي خادم static ثانٍ يشتغل بنفس الطريقة (مثلاً `npx serve`).

## تغيير الهوية (عند اعتماد اسم الشركة)

كل شيء في `app/index.html`:

- **اسم الشركة على الفواتير/الواجهة:** ابحث عن `brand:'الشركة التقنية'` و `sellerName:'الشركة التقنية'`.
- **العنوان (تبويب المتصفح):** سطر `<title>`.
- **الشعار:** استبدل ملف `logo.png` في الجذر (نفس الاسم).
- **إيميل/جوال:** `email:` و `phone:` في بلوك الإعدادات.
- **إيميل المدير (دخول لوحة الإدارة):** ثابت `ADMIN_EMAIL` — أضِف إيميل شريكك هنا عند الحاجة.
- معظم هذه الحقول قابلة للتعديل أيضاً من داخل النظام: **الإعدادات**.

> مفتاح التخزين المحلي صار `techco_erp_v1` (منفصل عن نظام إبراهيم سعود `ibsaud_erp_v1`).

## قاعدة البيانات (Supabase)

الربط في `app/index.html`:

```js
const SUPA_URL='...';   // رابط مشروع Supabase
const SUPA_KEY='...';   // المفتاح العام (publishable / anon)
```

✅ **تم التحويل لمشروع Supabase جديد خاص بالشركة** (`techco-erp`). النظام الآن موصول بقاعدة بيانات نظيفة منفصلة تماماً عن نظام إبراهيم سعود.

- كل الجداول والسياسات (RLS) والدوال والمخازن (`task-images`, `blog-images`) منشأة ومُختبَرة.
- السكربت الموحّد المستخدَم محفوظ في `supabase/_apply_all.sql` (والجداول الأساسية في `supabase/00_base.sql`).

### أول تسجيل دخول
النظام يستخدم حسابات Supabase Auth، والحساب الجديد لا ينتقل من المشروع القديم. لأول مرة:
1. افتح النظام → اضغط **«إنشاء حساب»** بالبريد `ibrahimsaud25@gmail.com` (= حساب المدير المحدّد في `ADMIN_EMAIL`) وكلمة مرور.
2. أكّد البريد من رسالة Supabase ثم سجّل الدخول.
3. لتغيير مدير النظام لاحقاً (أو إضافة شريكك): عدّل `ADMIN_EMAIL` في `app/index.html`.
4. الدخول عبر Google/Apple يحتاج تفعيل المزوّد في إعدادات Supabase أولاً (البريد+كلمة المرور يعمل مباشرة).

> دوال الفريق (الفريلانسرز) والعملاء تعمل عبر روابط/توكنات خاصة بلا حسابات.
